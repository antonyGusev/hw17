# SENTRY SWM-2 (fw_7) — Test Checklist

**Scope:** Complete SENTRY SWM-2 fw_7 PRD coverage: AC-1–AC-2, ST-1–ST-4, WF-1–WF-5, AU-1–AU-6, OTA-1–OTA-12, LM-1–LM-8, RL-1–RL-7, DS-1–DS-7, HL-1–HL-3, GD-1–GD-5, AL-1–AL-5, Buttons and System CLI.

**Firmware:** stable `2.1.0`; beta `2.3.0`. PASS/FAIL and Bug ID cells remain blank; firmware-specific tests are pre-marked `N/A` in the inapplicable version column. Results from fw_1.x do not apply.

**Automation:** `Automated (code updated)` means a matching fw_7 pytest scenario exists but still requires DUT/HIL execution. `Partial (code updated)` covers only the stated automated portion. `Not Automated` means no corresponding full fw_7 functional test was found. `Manual` indicates required manual observation or stimulus. No PASS/FAIL is inferred without a physical run.

**Applicability:** `N/A — 2.3.0 only` marks Guard/Alert/K4-dependent behavior; `N/A — requires 2.3.0 source` marks OTA tests that must start on beta; `N/A — 2.1.0 only` marks E099 compatibility checks on stable. All other cases apply to both versions; stable firmware must return E099 for unsupported Guard/Alert/K4 operations.
