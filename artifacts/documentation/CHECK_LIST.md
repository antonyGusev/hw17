# SENTRY SWM-2 (fw_7) — Test Checklist

**Scope:** Wi-Fi (WF-1–WF-5), Smart Lamp (LM-1–LM-8), OTA (OTA-1–OTA-12). Requirements from SENTRY SWM-2 PRD.

**Firmware:** stable `2.1.0`; beta `2.3.0`. `Current` is an optional field for a separate currently tested fw_7 build. All result and Bug ID cells are intentionally blank; results from fw_1.x do not apply.

**Automation:** `Automated (code updated)` means a matching fw_7 pytest scenario is present but still requires DUT/HIL execution. `Partial (code updated)` covers only the stated automated portion. `Manual` means the full PRD behavior has no reliable automated stimulus/observation yet. No PASS/FAIL is inferred without a physical run.

**Applicability:** Guard/Alert-dependent cases require FW `2.3.0`. For other cases, execute on both stable and beta. Mark unsupported version-specific cases `N/A` only when testing.
